# 🗄️ SQL Data Analytics & EDA Project | SSMS + SQL Server

A complete Exploratory Data Analysis (EDA) project built using **SQL Server Management Studio (SSMS)** and **SQL Server** to analyze sales, customer, and product data from a data warehouse environment.

This project focuses on transforming raw business data into meaningful insights using SQL queries, aggregations, joins, ranking analysis, and KPI reporting techniques.

---

# 🚀 Project Overview

The objective of this project was to:

- Build and manage a data warehouse database
- Import and structure raw datasets
- Perform exploratory data analysis (EDA)
- Generate business insights using SQL
- Practice real-world analytical querying techniques

The project includes:
- Database creation
- Schema management
- Data importing using BULK INSERT
- Dimension & Fact table analysis
- KPI generation
- Revenue analysis
- Ranking analysis
- Customer & product insights
